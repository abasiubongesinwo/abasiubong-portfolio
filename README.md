# Abasiubong Esinwo — Developer Portfolio

A modern, responsive personal portfolio website built to showcase my web development journey, skills, and projects.

## Overview

This portfolio was created as part of my journey into frontend and full-stack web development.

The website focuses on a clean, modern interface with smooth animations, responsive layouts, and a simple single-page experience.

I'm continuously improving the project as I learn new technologies and gain more practical development experience.

## Features

- Responsive design for desktop, tablet, and mobile
- Single-page portfolio layout
- Smooth section navigation
- Animated UI elements
- Interactive navigation menu
- Mobile-friendly navigation
- Project showcase
- Skills and technology section
- Contact section
- GitHub integration
- Modern dark-themed interface
- Responsive buttons and interactive elements

## Tech Stack
